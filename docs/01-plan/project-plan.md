## 1. 프로젝트 개요

### 1.1 프로젝트명
**올가 미수등 시스템** (OLGA Academy Management System)

### 1.2 프로젝트 목적
한국 대학입시 준비 학원 프랜차이즈를 위한 종합 시험 관리 및 AI 분석 시스템 개발

### 1.3 핵심 가치 제안
1. **Excel 기반 편리한 시험 입력** - 기존 업무 방식 유지
2. **실시간 자동 채점** - 1-9등급 즉시 산출
3. **AI 개인화 분석 보고서** - Google Gemini API 활용
4. **역할 기반 권한 관리** - 4단계 (관리자/지점/학생/학부모)
5. **다중 지점 통합 관리** - 프랜차이즈 본사 관점

## 2. 이해관계자

| 역할 | 설명 | 주요 니즈 |
|------|------|----------|
| **본사 관리자** | 전체 시스템 관리 | 통합 통계, 시험 관리, 지점 관리 |
| **지점 관리자** | 개별 지점 운영 | 학생 관리, 성적 분석, 시험 배포 |
| **학생** | 시험 응시자 | 편리한 응시, 성적 확인, AI 피드백 |
| **학부모** | 학생 보호자 | 자녀 성적 조회, 학습 상담 자료 |

## 3. 기능 요구사항

### 3.1 핵심 기능 (P0 - 필수)

#### F001: 사용자 인증
- 로그인/로그아웃
- 역할 기반 접근 제어 (RBAC)
- 세션 관리 (24시간)
- Impersonation (관리자 → 지점/학생/학부모)

#### F002: 지점 관리
- 지점 CRUD
- 지점 관리자 계정 생성
- 지점 표시 순서 관리
- 지점별 데이터 격리

#### F003: 시험 관리
- Excel 업로드 (45문제 표준 포맷)
- 시험 CRUD
- 문제 메타데이터 (난이도, 분류, 해설)
- 출제 경향 분석

#### F004: 시험 배포
- 다중 지점 동시 배포 (관리자)
- 반별/학생별 배포
- 응시 기간 설정
- 배포 현황 모니터링

#### F005: 시험 응시
- 문제 풀이 인터페이스
- 답안 임시 저장
- 시험 제출
- 자동 채점 (1-9등급)

#### F006: AI 분석 보고서
- Google Gemini API 연동
- 개인화 성적 분석
- 취약점 분석
- 학습 전략 제안
- HTML 보고서 생성

### 3.2 지원 기능 (P1 - 중요)

#### F007: 학생 관리

- 자녀 성적 조회

## 4. 비기능 요구사항

### 4.1 성능
| 항목 | 목표 |
|------|------|
| 페이지 로드 시간 | < 3초 |
| API 응답 시간 | < 500ms (일반), < 30초 (AI 보고서) |
| 동시 접속자 | 100명 이상 |

### 4.2 보안
| 항목 | 구현 |
|------|------|
| 비밀번호 | bcrypt 해싱 |
| 세션 | 24시간 만료, 서버 저장 |
| SQL Injection | ORM 파라미터화 |
| XSS | 입력값 이스케이프 |
| 데이터 격리 | branchId 기반 필터링 |

### 4.3 가용성
- 서비스 가용성: 99% 이상
- 데이터 백업: 일일 자동 백업

## 5. 기술 스택

### 5.1 프론트엔드
- React 18 + TypeScript
- Vite (빌드)
- Wouter (라우팅)
- TanStack Query (서버 상태)
- Tailwind CSS + Shadcn/ui
- Chart.js, Recharts

### 5.2 백엔드
- Node.js + Express + TypeScript
- Drizzle ORM
- express-session
- bcrypt
- multer, xlsx

### 5.3 데이터베이스
- PostgreSQL (Neon DB)

### 5.4 외부 서비스
- Google Gemini API (AI 분석)
- OpenAI API (대체)

### 5.5 인프라
- Frontend: Vercel/Netlify
- Backend: Railway/Render
- Database: Neon (서버리스 PostgreSQL)
